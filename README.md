# Studio Steven homepage starter

A small vanilla HTML/CSS/JavaScript starter based on the supplied desktop and mobile screenshots.

## Add your artwork

Put your exported images in `assets/` and use these filenames, or update the `src` values in `index.html`:

- `studio-steven-logo.svg` — header logo, ideally with a transparent background
- `studio-steven-logo-white.svg` — white footer logo
- `norwich-print-01.jpg` through `norwich-print-06.jpg` — each complete print artwork, including its NORWICH title and subtitle if those are part of the design

The image dimensions in the HTML are placeholders. Change `width` and `height` to each image's actual intrinsic dimensions to help browsers reserve the right amount of space while loading.

## Run locally

Open `index.html` in a browser, or use a local development server such as the VS Code Live Server extension.

## Before publishing

- Replace the placeholder artwork and logos.
- Confirm `about.html` and `shop.html` exist, or change those links to the correct destinations.
- Check all six image alt descriptions against the actual designs.
- Test keyboard navigation and the layout at narrow, medium and wide widths.
